# The Brief
To transform their website from a passive brochure into an active lead-generation engine, we designed and built a highly interactive ROI and value calculator for a growing B2B fintech client.

# The Challenge
B2B financial decisions require tangible proofs. Static PDF brochures were failing to keep visitors engaged, resulting in low sign-up rates and weak conversion metrics.

# The Solution
We built an interactive ROI calculator tool directly on their main landing page. Users input key business data and receive real-time, visual SVG charting detailing their potential return on investment.
