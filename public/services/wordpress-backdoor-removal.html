Why hacks come back

Cleaning the visible damage is not enough.

The signs

When a cleaned site gets reinfected, there is usually a backdoor left behind.

  • Malware returns days after a cleanup
  • Unknown admin accounts appear
  • Files change without anyone editing them
  • The host keeps suspending the site

Where backdoors hide

Places a quick scan tends to miss.

  • Disguised PHP files in uploads
  • Modified core or plugin files
  • Scheduled tasks that reinstall code
  • Database options and widgets

How it runs

Every change made against a full backup.

  1. 01

    Snapshot

    Full copy of files and database kept as evidence.

  2. 02

    Hunt

    Files compared with clean copies, uploads and tasks inspected.

  3. 03

    Remove

    Shells, rogue users and tasks removed, credentials rotated.

  4. 04

    Verify

    File changes monitored to confirm nothing returns.
