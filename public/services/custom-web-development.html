Custom code, or a platform?

Custom is not always the answer. When a platform fits, we say so and build on it.

A platform fits when

  • The site is mostly pages your team edits
  • You sell a standard catalogue with a standard checkout
  • Existing plugins or apps cover every feature
  • The budget does more as content than as code

We build on WordPress and Shopify too, and clean up hacked WordPress sites.

Custom code pays off when

  • People sign in and see their own data
  • Pricing, quotes or bookings follow your own rules
  • Several systems share data through APIs
  • Speed and accessibility are requirements
  • You want to own the code, not rent a theme

How a build runs

Five stages. Every milestone lands on a staging link before anything goes live.

  1. 01

    Discovery and architecture

    Requirements, content and integrations mapped, and a rendering choice made for each route before code is written.

  2. 02

    Schema and prototypes

    Typed data models and clickable interface prototypes, checked against real content.

  3. 03

    Build in milestones

    Front end, APIs and webhooks built in sprints, each one deployed to staging for review.

  4. 04

    Security and speed checks

    Core Web Vitals, cross-browser, input validation and header checks before launch.

  5. 05

    Launch and handoff

    Deployment, DNS, redirects and smoke tests, then the repository and its documentation are yours.

What it is built with

The project decides the stack. These are the defaults.

Application
Next.js, React, TypeScript
Static or server rendering chosen per route, with types shared from the database to the interface. See server and client components and state and API boundaries.
Content
Headless CMS or Markdown
Editors get structured fields; the front end stays free of theme limits.
Data
PostgreSQL, REST, webhooks
Relational models, verified webhooks and payment gateway flows, cached where latency calls for it.
Hosting
Vercel and CI/CD
A preview deployment for every milestone, and a staging link you can share with your team.
Standards
Speed, WCAG, JSON-LD
Measured against Core Web Vitals (how we approach it), checked by keyboard and screen reader, with structured data for search and AI search.
Handoff
Your repository
Code, documentation and deployment access move to your team at launch.
