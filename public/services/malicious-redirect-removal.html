How redirects hide

Many only trigger for some visitors, which makes them hard to catch.

Who sees it

Redirect malware often targets specific visitors to stay hidden from owners.

  • Only mobile visitors
  • Only visitors from Google
  • Only first-time visitors
  • Only at certain times

Where it lives

The places we trace a redirect back to.

  • Server rewrite rules
  • Injected JavaScript in themes or plugins
  • Database options and posts
  • Compromised third-party scripts

How it runs

We reproduce the redirect before removing it.
