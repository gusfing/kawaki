Fintech ROI Calculator

A concept build: a savings calculator that recalculates in the browser as each slider moves.

The project

The client

This is a concept project, built by Kawaki Studios to work through how an interactive financial calculator should behave, rather than for a client.

The brief

Many calculators send every change to a server and wait for the answer, so sliders lag and results flicker. The aim was a tool that recalculates instantly as you move a slider, with inputs that are checked and results that can be passed on.

What we built

  • Calculations that run in the browser, with no request per slider move
  • Typed, validated inputs for terms, rates and capital costs
  • Results stored as structured data that can be saved or exported
  • An optional webhook to send results to a CRM or document tool
