// 02. PROJECT BRIEF

Strategic Mandate & Operational Objectives

Institutional Context

BAZZARO is an independent direct-to-consumer lifestyle brand focused on everyday canvas accessories under the ethos 'Art You Carry'. Built with a transparent single-tier pricing model (100% heavyweight cotton canvas art-print totes at ₹600 flat with pan-India delivery), the brand requires a high-converting digital storefront combining editorial art direction with frictionless checkout flows.

Unlike mass-market polyester accessories, BAZZARO bags are cut, stitched, and screen-printed in small batches using archival pigment printing and fade-resistant screenprints. Collections span Botanical & Floral (vintage flora motifs), Anime & Manga (illustrated graphic drops), and Contemporary Graphic Art.

STRATEGIC IMPERATIVE

Standard Shopify templates looked generic, loaded sluggishly with third-party app scripts, and failed to convey the tactile craftsmanship of heavyweight canvas. BAZZARO needed an editorial digital flagship that feels like a modern art lookbook while delivering sub-second page loads and instant cart transitions.

Verified Project Objectives

OBJ 01

Eliminate E-Commerce Template Bloat

Replace sluggish Shopify themes and 30+ third-party app scripts with a custom Next.js App Router storefront delivering sub-second page transitions.

OBJ 02

Build an Instant Reactive Dual-Tab Drawer

Combine active Cart items and persistent Wishlist favorites into a single client-side slide-over drawer with zero full-page reloads.

OBJ 03

Communicate Heavyweight Cotton Canvas Craftsmanship

Design detailed material specification modules highlighting cotton GSM, reinforced X-stitching, internal utility pockets, and archival screenprinting.

OBJ 04

Streamline D2C Impulse Purchases

Incorporate native View Transitions API page morphs and persistent promotional incentives (Free Shipping on ₹2,999+, flat ₹600 pricing) to maximize checkout completion.

// 03. THE CHALLENGE & THE APPROACH

Operational Friction vs. Architectural Strategy

THE VERIFIED CHALLENGE

Real Constraints & Friction

Overcoming the sluggish page reloads, third-party plugin bloat, and cookie-cutter lookbooks typical of traditional template e-commerce.

Template Bloat & Slow Page Speeds

Standard e-commerce themes load 30+ external scripts for wishlist, cart, and reviews, causing mobile Largest Contentful Paint (LCP) times to exceed 4.5 seconds.

Cart & Wishlist Friction

Full-page cart reloads disrupt user shopping flow. The client required an instant slide-out drawer seamlessly unifying both active Cart items and saved Wishlist favorites.

Material & Craft Storytelling

Consumers purchasing ₹600 canvas totes online need immediate visual proof of fabric density (heavyweight GSM), reinforced X-stitching, and fade-resistant print quality.

Mobile First Checkout Ergonomics

Over 80% of D2C lifestyle traffic originates on mobile devices through Instagram and social channels, demanding thumb-friendly navigation and zero cumulative layout shift.

Brand Editorial Atmosphere

The digital storefront needed to feel like a high-end designer atelier while clearly communicating practical shipping perks (Free Shipping on ₹2,999+, 15% first-order discounts).

THE KAWAKI APPROACH

Architectural Response

We treated BAZZARO's e-commerce presence as an editorial gallery where every product is an art piece. Performance is treated as a core design feature: zero third-party script bloat, instant slide-over drawers, and native view transitions that feel like a native mobile app.

Next.js App Router & Turbopack

We engineered the storefront from scratch using Next.js App Router and Turbopack, pre-rendering product catalog pages into static HTML while streaming personalized client states.

Reactive Dual-Tab Drawer Engine

Rather than running separate third-party plugins, we built a custom client-side drawer combining Cart and Wishlist tabs (`drawer-tab-cart` / `drawer-tab-wishlist`) with zero layout shift.

View Transitions API Integration

We utilized native CSS `view-transition-name` attributes, allowing product cards to morph fluidly into product detail headers as customers navigate the store.

Editorial Design Tokens & Typography

We paired Bodoni Moda (High-fashion serif) with Libre Franklin (Utilitarian grotesk) and tailored color tokens (`bg-cream`, `text-ink`, `accent-crimson`) reflecting natural canvas.

// 06. ARCHITECTURAL & CRAFT DEEP DIVE

Production Engineering & System Hardening

A detailed examination of the verified fullstack infrastructure, state hydration boundaries, and API gateways powering BAZZARO.

01 / Frontend & Client Runtime

Engineered using Next.js App Router, React 19, TypeScript, and Tailwind CSS. All styling tokens are purged at build time, resulting in a featherweight CSS payload under 45KB.

02 / API & Real-Time Gateway

RESTful headless product data endpoints with localized client storage caching for instant wishlist persistence.

03 / State Management & Persistence

Structured product catalog schemas maintaining clean separation between product variants, stock status, and collection tags.

04 / Security & Performance Discipline

Core Web Vitals scores exceeding 95 across Mobile and Desktop. Largest Contentful Paint (LCP) under 1.1s, Cumulative Layout Shift (CLS) of 0.00.
