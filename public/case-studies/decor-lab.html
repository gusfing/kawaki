// 02. PROJECT BRIEF

Strategic Mandate & Operational Objectives

Institutional Context

Established in 1993 by Raja Sinha and carried forward by Rajdip Sinha (The Bartlett School of Architecture, UCL), Decor Lab is a 33-year-old architectural institution headquartered in Kolkata. With more than 1,300 completed projects, a 275-member team, and commissions across 15 Indian cities, the firm bridges traditional craftsmanship with cutting-edge computational parametric design.

Decor Lab's landmark commissions include the Patna Penthouse (a double-height luxury duplex with custom marble inlays), the Santhaliya Residence in Kolkata (a raw plaster minimalist retreat), and the Jai Alankar Jewellers luxury showroom in Muzaffarpur. The studio's work has been recognized in the Blindwink India Design Awards, Forbes India, and GoodHomes.

STRATEGIC IMPERATIVE

Decor Lab needed a digital experience that reflects their evolution from traditional architecture into an innovative parametric and fluid design studio. The site had to honor three decades of Indian architectural heritage while positioning them at the technological forefront of international computational design.

Verified Project Objectives

OBJ 01

Honor 33-Year Institutional Heritage with Parametric Innovation

Bridge three decades of Indian architectural practice (founded 1993, 1,300+ sites) with the Bartlett UCL computational design leadership of Rajdip Sinha.

OBJ 02

Engineer Stutter-Free Hardware-Accelerated Video Kinematics

Implement a full-bleed ambient background video hero utilizing CSS translate3d and intersection observers to auto-pause off-screen playback and conserve device battery.

OBJ 03

Build a Tactile Horizontal Spatial Gallery

Map vertical mouse-wheel input to smooth horizontal panning across flagship projects (Patna Penthouse, Santhaliya, Jai Alankar) with real-time progress indicators.

OBJ 04

Establish Public Engineering Authority

Incorporate verified Kawaki Studios production engineering attribution directly in the live production footer ('Site by Kawaki Studios — Made with precision in Kolkata, India').

// 03. THE CHALLENGE & THE APPROACH

Operational Friction vs. Architectural Strategy

THE VERIFIED CHALLENGE

Real Constraints & Friction

Balancing cinematic ambient video backdrops, horizontal spatial project sliders, and smooth cursor kinematics without causing device overheating or mobile lag.

Existing Experience & Narrative Fragmentation

Prior web representations failed to communicate the studio's three design pillars: Functionality First, Material Innovation, and Fluid Parametric Architecture.

Technical Constraints of Video Delivery

Full-bleed background video heroes often stutter, freeze DOM rendering, or drain mobile device batteries if not handled with GPU compositing and memory management.

Horizontal Scroll Ergonomics

Creating an intuitive horizontal spatial gallery that responds naturally to mouse wheel scrolling on desktop while preserving native vertical touch scrolling on mobile.

Parametric Visual Representation

Communicating complex fluid curves and algorithmic geometries through clear typographic pacing, interactive project reels, and spatial photography.

Performance & Cold Start Speeds

Delivering heavy cinematic multimedia while keeping initial DOM loads under 1 second and adhering to strict Core Web Vitals thresholds.

THE KAWAKI APPROACH

Architectural Response

We envisioned the Decor Lab flagship as a living spatial environment. Just as parametric architecture creates organic, unbroken spatial transitions, the website's kinematics should flow seamlessly between video backdrops, horizontal project reveals, and tactile cursor feedback.

Next.js App Router Architecture

We utilized Next.js with React Server Components (RSC) to render core page layouts statically at the edge, hydrating only interactive kinematic islands on the client.

Hardware-Accelerated Ambient Video Engine

We engineered an optimized video container using CSS `translate3d` and GPU compositing, accompanied by intersection observers that automatically pause video playback when scrolled out of view.

Horizontal Spatial Project Slider

We built a smooth, progress-tracked horizontal slider allowing visitors to glide through flagship commissions (Patna Penthouse, Santhaliya, Jai Alankar) with timeline indicators.

Interactive Mix-Blend Cursor Layer

A custom cursor layer with difference mix-blend modes provides subtle tactile feedback as visitors hover over interactive architectural imagery and navigation nodes.

// 06. ARCHITECTURAL CRAFT & PERFORMANCE

Visual Ergonomics & Sub-Second Asset Delivery

Visual Direction & Layout Grid

Aesthetic Thesis: Fluid luxury, dark ambient backgrounds, architectural precision, and computational sophistication.

Typography Hierarchy: Host Grotesk (Clean modern headings with geometric proportions) paired with Space Mono (Technical coordinates, timeline markers) and Plus Jakarta Sans (Narrative body).

Viewport Scaling: Fluid clamp viewport scaling (`clamp()`) ensuring typography and section heights adapt organically to any screen width. Horizontal snap containers with custom scrollbar hiding.

Asset Optimization & Core Web Vitals

Performance Discipline: 60fps steady frame rate during complex horizontal scroll transforms through CSS `translate3d` hardware layers and passive event listeners.

Frontend Architecture: Built with Next.js App Router, React Server Components, and Tailwind CSS. Client-side interactivity is encapsulated in isolated islands, ensuring minimal hydration overhead.

Responsive Mechanics: Comprehensive multi-tier media queries and CSS clamp functions ensuring smooth visual scaling from compact mobile screens up to expansive 4K architectural drafting monitors.
