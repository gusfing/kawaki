# SEO Strategy for Kawaki Studios

## Executive Summary

Kawaki Studios is an independent web development studio based in Delhi, India, specializing in custom Next.js web applications, headless commerce, and bespoke interfaces. This strategy positions Kawaki as the go-to "editorial engineering" studio for high-growth ventures refusing generic templates.

**Business Type:** Digital Agency / Web Development Studio  
**Target Market:** B2B — SaaS companies, e-commerce brands, fintech, healthcare tech, architecture firms  
**Geographic Focus:** India (Delhi NCR primary), Global remote clients  
**Primary Keywords:** "web development studio Delhi", "Next.js agency India", "headless Shopify development", "custom web application development"

## 4. Technical SEO Foundation

### Current State Assessment

| Element | Status | Action Required |
|---------|--------|-----------------|
| **Robots.txt** | ✅ Basic (allows all, disallows /api/) | Add staging disallow, sitemap reference |
| **Sitemap.xml** | ⚠️ Homepage only | Generate full sitemap with all service/industry/work pages |
| **Schema Markup** | ✅ Organization, FAQ, Article | Add ProfessionalService, Service, CaseStudy schemas |
| **Core Web Vitals** | ✅ Targets stated (95+ Lighthouse, 0ms CLS) | Verify with CrUX data, add to schema |
| **Canonical URLs** | ✅ Implemented in metadata | Verify on all pages |
| **Hreflang** | ❌ Missing | Add if targeting multiple languages/regions |
| **Page Speed** | ✅ Good (Next.js static export) | Monitor, optimize images |

### Required Technical Improvements

1. **Complete Sitemap Generation** — Dynamic sitemap.ts covering all routes
2. **Enhanced Schema** — ProfessionalService, Service, Project/CaseStudy schemas per page
3. **Image Optimization** — Next/Image with AVIF/WebP, explicit dimensions, priority loading
4. **Structured Data Testing** — Validate all schemas with Google Rich Results Test
5. **International SEO** — hreflang for en-IN, en-US if targeting globally
