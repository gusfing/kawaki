How it works across time zones

Five stages, each ending on a staging link you can review on your own schedule.

  1. 01

    Discovery call

    A call in your overlap hours about the site, the users and what it must connect to.

  2. 02

    Written scope

    Milestones, a fixed price for each and the date each one lands on staging.

  3. 03

    Build in milestones

    Work happens in a Git repository; each milestone is deployed to staging with a short written update.

  4. 04

    Review and fixes

    You test on staging when it suits you; changes go back into the next milestone.

  5. 05

    Launch and handoff

    Deployment, DNS and redirects, then the repository and its documentation are handed over.
