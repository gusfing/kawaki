## 1. Project Summary & Background
Kova is a proprietary AI-powered web generation platform engineered by Kawaki Studios. Addressing the rigid constraints of traditional site builders and the unpredictable outputs of raw AI code generators, Kova introduces an interactive **visual canvas** where users can generate, manipulate, and refine web components using natural language prompts.

Users describe functional layouts, section hierarchies, or design tokens in plain language; Kova's generative engine synthesizes semantic HTML, CSS styling, and interactive layouts in real time, rendering them directly onto an infinite interactive canvas with live visual editing controls.

## 3. Verified Technical Architecture & Product Capabilities (Repository Verified)
* **Core Technology Stack:**
  * `Frontend Framework:` Next.js with React server components
  * `Visual Canvas Engine:` Dynamic infinite canvas with drag-and-drop spatial placement and zoom controls
  * `Prompt-Based Generation Pipeline:` Bounded LLM synthesis transforming text prompts into structured, modular UI components
  * `Design Token System:` Automated color palette extraction, typography pairing, and spacing grid harmonization
  * `Real-Time Preview Isolation:` Sandboxed iframe execution preventing generated scripts from leaking into canvas state
* **Core Workflow Phases:**
  1. *Prompt Ingestion:* Structured parsing of user requirements (industry, design style, target conversion goal).
  2. *Section Blueprint Synthesis:* Generates semantic component blocks (Hero, Features, Pricing, Proof, FAQ).
  3. *Visual Canvas Editing:* Inline text updates, component re-ordering, style adjustments, and responsive preview toggling (Desktop, Tablet, Mobile).
  4. *Clean Code Export:* One-click export to clean, standards-compliant HTML/Tailwind markup with zero vendor lock-in runtime scripts.

## 7. Recommended Case Study Narrative
1. **The Product Problem:** Traditional website builders force users into repetitive manual drag-and-drop tasks, while current AI code tools generate black-box code that non-developers cannot easily edit or customize.
2. **The Kova Architecture:** How Kawaki designed a visual canvas engine that treats AI as an assistant rather than a rigid generator—allowing creators to generate sections iteratively, customize copy visually, and export production-ready code.
3. **Engineering the Canvas Experience:** Managing real-time DOM updates, responsive iframe sandboxes, and low-latency LLM streaming without browser rendering stutter.
